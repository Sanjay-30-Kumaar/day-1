# Day 1 Personal Profile Website

A responsive single-page personal profile website built using semantic HTML5, CSS Flexbox, CSS Grid, and JavaScript.

## Features

- Responsive personal profile layout
- Semantic HTML5 structure
- Flexbox navigation and header
- CSS Grid skills section
- Random quote API integration
- Mobile-friendly design

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages
